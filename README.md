# QuantumTrade Website

A modern React website for QuantumTrade, featuring advanced trading bot solutions powered by cutting-edge algorithms and machine learning technology.

## Features

- Responsive design with modern UI
- Multiple pages including Home, Features, Pricing, About, and Contact
- Styled with styled-components
- Animations with Framer Motion
- Icons from React Icons

## Technologies Used

- React
- React Router
- Styled Components
- Framer Motion
- Vite

## Development

```bash
# Install dependencies
npm install

# Start development server
npm run dev
```

## Deployment

This project is configured for GitHub Pages deployment:

```bash
# Build and deploy to GitHub Pages
npm run deploy
```

## Project Structure

- `/src/components` - Reusable UI components
- `/src/pages` - Page components
- `/src/assets` - Images and other static assets
- `/src/styles` - Global styles
